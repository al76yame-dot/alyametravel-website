# موقع اليامي للسفر والسياحة

موقع إلكتروني فاخر متعدد الصفحات لـ **اليامي للسفر**.

## الصفحات (5)
1. `index.html` — الرئيسية
2. `services.html` — خدماتنا (9 خدمات)
3. `destinations.html` — الوجهات (12 وجهة)
4. `offers.html` — العروض الحصرية
5. `contact.html` — تواصل معنا (نموذج → info@alyametravel.com)

## رفع الموقع على Hostinger
1. ادخل لوحة Hostinger → **Files** → **File Manager**
2. افتح مجلد `public_html`
3. ارفع كل الملفات والمجلدات من هذا المشروع:
   - `index.html`, `services.html`, `destinations.html`, `offers.html`, `contact.html`
   - مجلد `css/`
   - مجلد `js/`
   - مجلد `images/` (إن وُجد)
4. الموقع راح يفتح على `alyametravel.com` مباشرة.

## إعداد البريد
- نموذج التواصل حالياً يفتح بريد العميل (mailto) ويرسل إلى `info@alyametravel.com`.
- لو تبي إرسال مباشر بدون فتح إيميل، نحتاج نضيف خدمة مثل Formspree أو نربط بـ Hostinger Email + PHP.
